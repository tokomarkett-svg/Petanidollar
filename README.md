# 🚜 PetaniDollar

> **Tanam cuan tiap hari → panen dolar.** Satu dashboard buat SEMUA sumber penghasilan online yang terbukti bayar (riset 2026): captcha, mikrotugas AI, survei, tes website, nulis, terjemahan, ngajar, produk digital, sampai freelance.

**Ini alat bantu disiplin, BUKAN bot captcha.** Semua kerja tetap lo kerjain sesuai aturan platform — bot = akun banned + saldo hangus.

Tiap platform punya badge: ✅ **Bisa dari Indonesia** / 🌏 **Butuh Inggris bagus** / 🚧 **Negara terbatas** — plus estimasi rate, minimal tarik, dan metode pembayaran.

## ✨ Fitur Dashboard

- 🏆 **Peta Cuan Global** — katalog lengkap + filter kategori + pencarian
- 📊 **Statistik target** — target minggu, terkumpul, hari ini, sisa
- 📈 **Progress bar** mingguan & harian (har = minggu ÷ 7)
- ⚡ **Catat cepat** — tombol `+$0.25/+$0.50/+$1/+$2` dari platform mana pun
- 🔢 **Mode 2Captcha** — ketik jumlah captcha, otomatis dihitung ke dolar
- 💰 **Saldo per platform** + bar progres + alarm **"SIAP CAIR 💸"**
- 🧾 **Tombol TARIK SEKARANG** — catat penarikan, saldo balik 0
- ⏱️ **Timer sesi kerja** (25/15/5 menit)
- ⬇️ **Ekspor CSV** ke Excel/Google Sheets
- ⚙️ **Pengaturan fleksibel** — target, rate, rate captcha, minimal tarik tiap platform
- 🚨 **Alarm scam** — pengingat anti-tipu

**Data 100% di perangkat lo** (localStorage). Tanpa server, tanpa kirim data ke mana-mana, jalan offline.

## 🚀 Deploy ke Vercel (gratis, tanpa ngoding)

1. Buka **vercel.com** → **Sign Up** → "Continue with GitHub" (login pake akun `tokomarkett-svg`)
2. **Add New… → Project** → pilih repo **Petanidollar** → **Import**
3. Biarkan semua default → **Deploy** → ±1 menit → dapet link:
   **`https://petanidollar.vercel.app`** 🎉

> 🔥 Setiap lo update file di repo, Vercel auto-deploy sendiri. Nggak perlu ngapa-ngapain.

**Pasang di HP:** buka link di Chrome → menu ⋮ → **Add to Home Screen** → kayak aplikasi beneran.

## 📅 Strategi Pemakaian

| Minggu | Fokus |
|---|---|
| 1 | 2Captcha (tanpa batas) + Toloka + Freecash → target $20 |
| 2–4 | Tambah Clickworker/UHRS, Microworkers, Appen → target $40–60 |
| 2–6 | Mulai bangun profil Upwork/Fiverr (jual skill) |
| Bulan 2–3 | Proyek freelance pertama → $100–300/bln |
| Bulan 3+ | Naik rate, klien tetap → $500+/bln + produk digital pasif |

**Aturan emas:** daftar gratis → kerja → saldo kebaca → tarik dana. Nol rupiah keluar. Minta deposit = scam, kabur.
